# 🎨 Design Studio — Telegram-бот + мини-приложение

Бот и мини-приложение для приёма заказов на дизайн: портфолио, услуги и цены, заявки и полноценная админ-панель прямо в Telegram.

## Что внутри

**Для клиентов (мини-приложение):**
- Главная: аватар, имя, специализация, цифры, направления, избранные работы, этапы работы
- Портфолио: фильтр по категориям, галерея с листанием, кнопка «Хочу похожий дизайн»
- Цены: услуги по категориям, срок, что входит, кнопка «Заказать»
- Форма заказа: услуга, задача, бюджет, сроки, референсы, контакт
- «Мои заказы» со статусами

**Для тебя (админ-панель — вкладка «Админ», видна только тебе):**
- Заявки: фильтры, смена статуса, чат с клиентом, сообщения клиенту через бота, личные заметки
- Работы: добавить / изменить / удалить, загрузка фото с телефона, обложка, закрепление на главной
- Услуги: цены, сроки, состав, порядок, скрыть/показать
- Профиль: аватар, тексты, контакт, валюта, цифры, категории, «Принимаю заказы» вкл/выкл

**Бот:**
- `/start` — приветствие + кнопка открытия мини-приложения, цены, контакт
- Мгновенное уведомление о новой заявке с кнопками «Взять в работу / Отклонить / Готово»
- Клиент автоматически получает сообщение при смене статуса
- `/admin` — статистика, `/orders` — активные заявки, `/id` — узнать свой ID

Картинки портфолио хранятся в Telegram (бесплатно и без ограничений хостинга), данные — в бесплатной MongoDB Atlas.

## 🚀 Запуск (бесплатно, ~20 минут)

### 1. Создай бота
1. Открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя и username.
2. Скопируй **токен** (вида `1234567890:AA...`).
3. Узнай свой **Telegram ID**: напиши [@userinfobot](https://t.me/userinfobot).

### 2. Создай бесплатную базу MongoDB Atlas
1. Зарегистрируйся на [mongodb.com/atlas](https://www.mongodb.com/cloud/atlas/register).
2. Создай бесплатный кластер **M0 (Free)**.
3. **Database Access** → добавь пользователя с паролем.
4. **Network Access** → *Add IP Address* → `0.0.0.0/0` (разрешить отовсюду).
5. **Connect → Drivers** → скопируй строку вида
   `mongodb+srv://user:ПАРОЛЬ@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority`

### 3. Загрузи код на GitHub
Создай новый репозиторий на [github.com/new](https://github.com/new) и загрузи туда все файлы этой папки (кнопка *uploading an existing file*). Файл `.env` загружать **не надо**.

### 4. Размести на Render (бесплатно)
1. Зайди на [render.com](https://render.com) через GitHub.
2. **New → Web Service** → выбери свой репозиторий.
3. Настройки:
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
4. **Environment Variables**:
   | Ключ | Значение |
   |---|---|
   | `BOT_TOKEN` | токен от BotFather |
   | `ADMIN_IDS` | твой Telegram ID |
   | `MONGODB_URI` | строка из Atlas |
5. Нажми **Deploy**. Адрес сервиса (`https://xxx.onrender.com`) Render подставит сам в `PUBLIC_URL`.

### 5. Готово!
Открой своего бота → `/start`. Появится кнопка «Открыть портфолио» и кнопка меню «Портфолио» слева от поля ввода. Тебе (админу) будет видна вкладка **Админ**.

**Первым делом:** вкладка Админ → **Профиль** (имя, аватар, username, тексты) → **Услуги** (свои цены) → **Работы** (удали демо и загрузи свои).

### 6. Чтобы бот не «засыпал»
Бесплатный Render усыпляет сервер через 15 минут без запросов (первое открытие потом грузится ~30–50 сек). Чтобы этого не было:
1. Зарегистрируйся на [uptimerobot.com](https://uptimerobot.com) (бесплатно).
2. *Add New Monitor* → HTTP(s) → URL: `https://xxx.onrender.com/health` → интервал 5 минут.

## 💡 Полезное

**Красивое оформление бота в @BotFather:**
- `/setuserpic` — аватар бота
- `/setdescription` — текст на пустом экране бота («Закажи дизайн: логотипы, соцсети, афиши…»)
- `/setabouttext` — описание в профиле бота
- `/newapp` — можно создать прямую ссылку на мини-приложение вида `t.me/твойбот/app` (URL — адрес сервера). Ссылку удобно ставить в шапку Instagram.

**Хранилище картинок.** По умолчанию загруженные фото бот складывает в твою личку с ботом (сообщения с подписью «файл портфолио — не удаляйте»). Чтобы они не мешали, создай приватный канал, добавь бота админом, узнай ID канала (перешли пост из канала боту [@userinfobot](https://t.me/userinfobot)) и пропиши его в `STORAGE_CHAT_ID`.

**Несколько админов:** `ADMIN_IDS=111111,222222`.

**Ссылки на разделы:** `https://xxx.onrender.com/?tab=prices`, `?tab=works`, `?order=1` (сразу открыть форму заказа).

## 🖥 Локальный запуск (для проверки)

```bash
npm install
cp .env.example .env     # можно ничего не заполнять
npm run dev              # http://localhost:3000
```
В режиме `DEV_MODE=true` мини-приложение открывается в обычном браузере, и ты сразу видишь админку. Данные хранятся в `data/db.json`.

## Структура

```
src/server.js    — сервер, API, загрузка картинок, вебхук
src/bot.js       — команды бота и уведомления
src/db.js        — MongoDB или локальный JSON
src/auth.js      — проверка подписи Telegram
src/defaults.js  — стартовые данные (услуги, категории, демо-работы)
public/          — мини-приложение (HTML/CSS/JS)
```
